# PRD: JJ Granados Technical Portfolio

## Vision
Build a fast, credible portfolio for a Senior Software Engineer demonstrating scalable mobile and cross-platform architecture, designed to attract tier-one tech companies and enterprise engineering managers.

## User Needs

### Recruiter
- Identify seniority and specialization quickly.
- Verify relevant experience and tech stack alignment.
- Find résumé and contact information.

### Engineering Manager / Staff Engineer
- Evaluate architectural depth and system design capability.
- Understand problem-solving ability in high-scale or high-complexity environments.
- Inspect migration, modernization, and technical debt mitigation experience.

### Client
- Understand difficult problems the engineer can help solve.
- See evidence of mobile modernization and cross-platform work.
- Find an easy contact path.

## Functional Requirements

### FR-01 Professional Positioning
Communicate Senior Software Engineer, Mobile & Cross-Platform, and the statement "Mobile engineer. Software builder. Problem solver."

### FR-02 Selected Work
Present GCash (emphasizing 100M+ downloads scale), Xamarin to .NET MAUI, Damstra Learn, and Tara Tsek.

### FR-03 Case Studies
Each case study contains Overview, Role, Technology, Problem, Constraints, Approach, Technical Decisions, Implementation, Validation, Business & Scale Impact, and Lessons Learned. Incorporate system architecture block diagrams where appropriate.

### FR-04 Engineering Approach
Show Understand, Investigate, Plan, Build, Validate, Scale/Improve.

### FR-05 Career Story
Show continuous progression from approximately 2014 Systems Engineer through Android and cross-platform engineering to current Senior Software Engineering.

### FR-06 Independent Projects
Present high-complexity deployed projects (e.g., TaxPH 2.0, Pet Records) without labeling them as "archived" or "planned" to maintain a premium signal.

### FR-07 Toolbox
Group technologies by category; do not use proficiency percentages. Emphasize big-tech stacks (Cloud, CI/CD, Testing) alongside mobile frameworks.

### FR-08 Experience
Provide a concise professional timeline.

### FR-09 Developer Velocity (AI-Assisted Engineering)
Demonstrate practical AI use for code review, debugging, contract testing, documentation, research, and CI/CD acceleration to showcase modern workflow efficiency.

### FR-10 Contact
Provide Email, LinkedIn, GitHub and Résumé.

### FR-11 Responsive
Support desktop, tablet and mobile.

### FR-12 Accessibility
Semantic HTML, keyboard navigation, focus states, contrast, reduced motion and accessible controls (WCAG 2.2 AA).

### FR-13 SEO
Metadata, Open Graph, sitemap, robots and structured data where appropriate.

### FR-14 Content Extensibility
A new case study should be addable without changing application logic.

## Non-Functional Requirements
- Static-first performance
- High maintainability
- Minimal runtime dependencies
- No unnecessary backend
- WCAG 2.2 AA practices where practical
- Strong Core Web Vitals

## V1 Acceptance
Homepage and all four case studies are responsive, accessible, SEO-ready and free of fabricated professional claims. Metrics and scale for GCash and other projects are factual and demonstrably true.
